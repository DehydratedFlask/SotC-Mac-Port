  return is substituted.

  the entries are at `0x3268080`, 16 B stride, `0x10000` mode stride and 4096-entry capacity.
- The parser normalizes CR/LF to NUL, strips a UTF-8 BOM, skips space/control bytes,
  finds the first token, advances by `strlen(remainder)+1`, and stores one
  `{int table_index, u32 reserved, const char* comma_plus_one}` record. This matches the
  original's one-record-per-buffer behaviour; the retained text allocation keeps the
  absolute `rest` pointer valid.
