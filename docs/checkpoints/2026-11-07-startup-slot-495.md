The operand/control-flow pins were decoded from the bytes, not carried over from a neighbour:

```
tag = (kind << 28) | count
  0x0 element   acc.c += count
  0x1 leaf      acc.b += 1 ; acc.a += count
  0x2 group     recurse(sub, depth+1) ; acc.b = 1 + sub.b*count + acc.b
                                      ; acc.a += sub.a*count ; acc.c += count*sub.c
  0x3 end       no change, stop
  0xbeefbeef    no change, stop
```

- **Validator** (`0xa39eb0`) takes `status = {flag, invert}`. The parser seeds it with
  `movw $0x101` → `{1,1}`; a **group** recurses with a fresh `{1,0}` (`movw $0x1`); element/leaf do
  `flag &= (count != 0)`; a group does `flag &= (count != 0) && sub.flag`; kind 3 does
  `flag &= (invert ^ 1)` and stops; the terminator does `flag &= invert` and stops; any other tag
  clears the flag. `%rsi` is the status pointer, `%rdi` the cursor, and the kind mask is `0xf0000000`
  compared against `0x1fffffff` first (`kind ∈ {0,1}` share one arm).
- **Accumulator** (`0xa39fd0`) has `a` at `+0`, `b` at `+4`, `c` at `+8`. Each of the parser's three
  passes stages `movabs $0x100000000` into the first qword and `movl $0` into the third, i.e. it starts
  from `{a=0, b=1, c=0}` — not from a zeroed accumulator.
- **Record** (`0x28` B): `+0x00` u8 valid (`setne (%r14)`), `+0x04` a = `c + a`, `+0x08` size = `a`,
  `+0x0c` bits = `b`, `+0x10` bytes = `(bits + 7) >> 3`, `+0x14` total = `size + bytes`,
  `+0x18` data, `+0x20` control.
- **Allocation order**: the first 4-byte refcount is allocated and stored at `+0x20` *before* the
  validity test, so even an invalid blob leaves a pointer there; when valid, the body scans for
  `0xbeefbeef`, allocates `4 * (index + 1)` bytes, copies (inlined 8/4/2/1 prefix then `0xf8f470`),
  allocates a second refcount, then `decl (%r15)` and tail-jumps to `0x170c0` (the first refcount is
  always released, because it was just set to 1).

Port contracts, all fail-closed with `ok == false` *before* the affected store: recursion depth > 64,
a caller-supplied dword count exceeded (the original reads unbounded), more than 4096 dwords, an
allocator hook without a matching release hook, and arena exhaustion when no hooks are supplied.

For the slot's static blob `{0x10000020, 0xbeefbeef}` the record is **valid 1, a `0x20`, size `0x20`,
bits 2, bytes 1, total `0x21`**, payload = those two dwords.
