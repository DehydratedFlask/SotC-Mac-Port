## Verification

The Init slice fixture supplies a malloc/free key seam, a `platform_tag` returning `0x11223344`
(fourcc `crmp` ×7, `calt` ×2), and release hooks that free the data/control. It asserts per
fragment: `key_release.ok`, `had_control`, `previous == 1`, `was_last`, `destroyed`, `freed`,
`key_size`, `key_capacity`, `key_hash`. A `resource_pool_miss` case asserts `previous == 2`,
`!was_last`, `!destroyed`, `!freed`, then releases the remaining reference.

Mutations: a shortened literal fails `static_assert`; a skipped release makes the fragment
`ok == false` and stops `base_initialize_255130`.

## Residual risks

- Production has no key allocator or platform-tag table yet, so the lifted chain stops visibly at
  the first attach by design; a host must install both.
- `resource_pool_miss` is a boolean model; the 0x138 B pool, its map and `*0x2ee2d00` are not
  modelled.
- `key_hash` depends on the host tag; only the test constant has a pinned value.
