## Corrections to E570

1. `0xac5260` and `0xac5320` are **functions (consumers), not tables**. `0x2569d0` holds 236 + 23
   unrolled `call` sites and has **zero backward branches**: there is no loop and no static array.
   Each row is a 16-byte stack record built 3–7 instructions before the call.
2. Map B is `{f32 lo, f32 hi, f32 v, u32 tag}`, not `{u64 pair, f32 v, u32 tag}`. The "pair" was a
   float range; `0xfc3350` is `{-FLT_MAX, +FLT_MAX}`, not `{INT_MAX, FLT_MAX}`.
3. 139 of the 259 sites are reachable, but one run emits **134** inserts (RetailBuild = 1) or
   **137** (gate = 0). Eight keys `0x7b..0x82` are inserted **twice** per run, so the sink must be a
   multimap; a `std::map` silently drops 8 rows.
