Chosen as the #1 rank in `docs/STARTUP_GAP_SURVEY.md`. Modelled by hand because its blocker is three
bespoke preamble tables the generator's row accounting refuses.

- Table word `0x2dd70e0 - 8*570 = 0x2dd5f10`; body 740 B, sha256
  `506dcf2a0047d9d6f34b85c76d34eb755332b6878afcdfd51d748b2055c18255`; padding `90909090`.
- Strings: `mem_Verify` @ `0xf9489c`, `Memory` @ `0xf948a7`, `Verify Memory Integrity` @ `0xf948ae`.
- Preamble: flags `0x2dd9f80..f8c`; four zero cells `0x2dd9f90/fa8/fc0/fd8` (dword 0 at `+0x00`,
  16 zero bytes at `+0x08`, `+0x04` and the sentinel gap never written); `xchgq` cell `0x2dd9ff0`;
  self-referential sentinel `0x2dda000` (`+0x38` → self, `0xffff…ff`, cap `0x80`); zeroed 0x18 block
  `0x2dfa440`; triple `0x2dfa460 = {0x2dfa480, 0x2dfa480, 0x2dfa930}`.
- Atexit order from this body: `0x11070/0x2dd9ff0`, `0x11080/0x2dfa440`, `0x11090/0x2dfa460`,
  `0x20b0/&var`, `0x272d0/&toggle`.

**Observation, not inference:** the shared menu shape `0x268b0` records the registry root destructor
(`0x27280`) on first use, between the bool record and the item record, so the registry holds six
records while five come from this body. The fixture asserts `+ 1` and locates both by search rather
than by a fixed index. `DebugMenuItem.registered` stays **0**, matching the slot-446 fixture.
